# 프롬프트 엔지니어링 변경사항

## 대화형 질문 입력

- 프로그램 실행 후 `질문>`에서 여러 질문을 연속으로 입력할 수 있도록 변경함.
- 빈 줄 또는 `q / quit / exit / 종료` 입력 시 종료됨.
- 기존 `--question`을 이용한 단건 질문 방식도 유지함.

## 차종 자동 인식

- 질문에 포함된 차종을 인식해 해당 차량의 FAISS 필터로 자동 전환함.
- 지원 차종: `avante / avante_hev / ioniq6 / nexo / tucson`
- 한글명과 영문명 모두 인식함.
- 질문에 차종이 없으면 마지막으로 인식한 차량을 유지함.
- 첫 질문에도 차종이 없으면 질문에 차종을 포함해 달라고 안내함.
- 이전 질문·답변 전체가 아니라 마지막으로 선택된 차종만 유지함.

## 답변 생성 길이

- 답변이 문장 중간에서 끊기는 현상을 줄이기 위해 기본 최대 생성 길이를
  256토큰에서 512토큰으로 변경함.

## 제약형 프롬프트 보강

- 답변이 정확성 평가 대상임을 알리고 검색 문서의 근거를 신중하게 확인하도록 함.
- 질문과 직접 관련된 정보만 사용하고, 수치·단위·조건·차종을 답변 전에 다시
  대조하도록 함.
- 근거가 부족하면 추측이나 관련 없는 출처 없이 `해당 정보 없음`만 답하도록 함.
- 제약형 모델 답변에 위 문구와 불필요한 내용이 함께 나오면 최종 출력을
  `해당 정보 없음`으로 정규화함.
- 근거가 있으면 검색 문서 헤더의 실제 차종과 페이지를 출처로 표시하도록 함.

## 프롬프트 비교 5종

- 기존 `basic`을 Context + Question 기준선으로 사용함.
- 기존 `role`을 Role Prompt 비교군으로 사용함.
- 기존 `constraint`를 Instruction Prompt 비교군으로 사용함.
- 근거 있음·없음 예시를 제공하는 `few_shot`을 추가함.
- 초안의 주장과 문서 근거를 다시 대조하는 `verification`을 추가함.
- `--variant all` 실행 시 한 번 검색한 동일한 top-3 청크로 5종을 비교함.
- Qwen 정성 비교에서 Context + Question과 Role은 문서에 없는 답을 생성함.
- Few-shot은 할루시네이션을 줄였지만 근거가 있는 질문도 정보 없음으로 판단함.
- Instruction / Constraint와 Chain-of-Verification은 근거가 없는 질문에
  `해당 정보 없음`을 출력함.
- Chain-of-Verification이 이번 표본에서 근거가 있는 답변과 정보 부족 판단의
  균형이 가장 좋았음.

## 수업자료 기반 평가 지표

- `evaluation_metrics.py`를 추가해 BERTScore Precision/Recall/F1을 계산함.
- RAGAS의 Faithfulness, Answer Relevancy, Context Precision, Context Recall을
  계산함.
- 프롬프트별 응답 생성 시간을 함께 출력함.
- `--evaluate`에서만 평가를 수행하고, `--reference-answer` 또는 대화형
  `모범답안>` 입력으로 기준 답안을 받도록 함.
- RAGAS 평가 LLM은 Upstage Solar를 사용하므로 평가 실행 시 API 사용량이
  발생함.
- 관련 수업자료는 `lab.06_rag_evaluation.ipynb`이며, 강의 PDF에는
  BERTScore와 RAGAS 개념·실행 예제가 포함되어 있음.

## 답변 모델 교체 구조

- 기본 실행은 기존과 동일하게 로컬 `Qwen/Qwen2.5-3B-Instruct`를 사용함.
- 실행 옵션 `--provider`와 `--model`로 코드 수정 없이 답변 모델을 선택하도록 함.
- `.env`의 `UPSTAGE_API_KEY`를 사용해 `--provider upstage`로 Solar API를
  선택할 수 있도록 함.

## 확인 결과

- 5개 차종 질문에서 차종별 검색 필터가 자동 전환되는 것을 확인함.
- 각 차량으로 전환했을 때 해당 차량의 top-3 청크만 검색되고 Qwen 답변까지
  생성되는 것을 확인함.
- 동일한 top-3 검색 결과로 프롬프트 5종 답변을 비교 실행함.
- 제약형이 근거 부족 질문에 `해당 정보 없음`만 출력하는 것을 확인함.
- 대화형 질문 입력과 종료 명령 동작을 확인함.
- 실제 API 비용 없이 모의 응답으로 Upstage 모델 선택과 요청 전달을 확인함.
- 프롬프트, 차종 인식, 출력 제약, 모델 선택 및 평가 출력 단위 테스트 16개 통과.
